# AI Wallpaper Runtime Host

The Runtime Host is a local HTTP service for AI Wallpaper Engine runtime jobs.

It lets the browser editor submit safe structured jobs without directly executing Python, FFmpeg or model code in the frontend.

## Start

```bash
npm run runtime:host
```

Default URL:

```text
http://127.0.0.1:8787
```

Use another port if needed:

```bash
RUNTIME_HOST_PORT=8788 npm run runtime:host
```

Windows CMD:

```bat
set RUNTIME_HOST_PORT=8788 && npm run runtime:host
```

PowerShell:

```powershell
$env:RUNTIME_HOST_PORT=8788; npm run runtime:host
```

Health check:

```text
http://127.0.0.1:8787/api/runtime/health
```

## API

- `GET /api/runtime/health`
- `POST /api/runtime/jobs`
- `GET /api/runtime/jobs/:jobId`
- `POST /api/runtime/jobs/:jobId/cancel`

## Security

- Binds to `127.0.0.1` by default.
- Allows only the `liveportrait` provider in Sprint 21.
- Rejects `rawCommand`, `shellCommand`, and `executeCommand` fields.
- Treats `commandPreview` as metadata only.
- Restricts CORS to Vite dev origins.
- Provides no arbitrary file-read API.
- Output paths must be generated by the Runtime Host in a future sprint.

## Token

Development mode allows empty token.

For production-like local use, set:

```bash
set RUNTIME_HOST_TOKEN=your-token
```

Requests must then include:

```text
x-runtime-token: your-token
```

## Current Mock Mode

Sprint 21 does not execute LivePortrait.

Jobs move through:

```text
queued -> running -> completed
```

The completed output is mock metadata only.

## Dry Run Mode

Sprint 22 adds `mode: "dryRun"` for LivePortrait.

Dry run does not execute Python, FFmpeg or LivePortrait. It only generates:

- `commandPlan`
- `outputPlan`
- `dryRun: true`

Example request:

```json
{
  "providerId": "liveportrait",
  "providerKind": "portrait-motion",
  "mode": "dryRun",
  "runtimeConfig": {
    "mode": "localCli",
    "runtimePath": "D:/ai-runtimes/LivePortrait",
    "pythonCommand": "python",
    "entryFile": "inference.py",
    "outputDir": "D:/ai-wallpaper-runtime-outputs/liveportrait"
  },
  "input": {
    "sourceAssetId": "current-wallpaper",
    "sourceImagePath": "D:/images/source.png",
    "preset": "blink",
    "strength": 0.5,
    "duration": 5,
    "loop": true
  }
}
```

The Runtime Host generates output filenames itself. The browser must not provide arbitrary executable commands or output file paths.

## Real Run Mode

Sprint 23 adds `mode: "realRun"` behind a feature flag.

Real execution is disabled by default.

Enable it explicitly:

```bash
RUNTIME_ENABLE_REAL_EXECUTION=true npm run runtime:host
```

Windows CMD:

```bat
set RUNTIME_ENABLE_REAL_EXECUTION=true && npm run runtime:host
```

PowerShell:

```powershell
$env:RUNTIME_ENABLE_REAL_EXECUTION="true"; npm run runtime:host
```

`realRun` executes only the Runtime Host generated commandPlan. It never executes frontend supplied raw commands.

Execution uses:

- `child_process.spawn`
- `shell: false`
- separated command and args
- stdout/stderr capture with size limits
- 10 minute timeout

If the feature flag is disabled, `realRun` returns a failed job with:

```text
Real execution is disabled. Set RUNTIME_ENABLE_REAL_EXECUTION=true to enable it.
```

## Runtime Output Endpoints

Sprint 24 adds output metadata and video endpoints.

```text
GET /api/runtime/outputs/:jobId
GET /api/runtime/outputs/:jobId/video
```

The metadata endpoint returns the output lifecycle:

- `planned`: dry run output plan only.
- `available`: real run output MP4 exists and can be streamed.
- `missing`: real run completed but the expected MP4 is missing.
- `failed`: runtime job or output validation failed.

The video endpoint serves only the MP4 path generated by Runtime Host for that job.

Security boundaries:

- No arbitrary file-read endpoint.
- No `path` query parameter.
- No `filename` query parameter.
- The video path must come from the job output plan.
- The video path must stay inside `outputDir`.
- Only `.mp4` video output is served.
- Range requests are supported for basic video seeking.

The MP4 is an intermediate LivePortrait animation asset, not the final AI Wallpaper Engine export format.
