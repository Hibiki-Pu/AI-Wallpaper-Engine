# AI Wallpaper Runtime Host

The Runtime Host is a local HTTP service for AI Wallpaper Engine runtime jobs.

It lets the browser editor submit safe structured jobs without directly executing Python, FFmpeg or model code in the frontend.

## Start

```bash
npm run runtime:host
```

Default URL:

```text
http://127.0.0.1:8787
```

Health check:

```text
http://127.0.0.1:8787/api/runtime/health
```

## API

- `GET /api/runtime/health`
- `POST /api/runtime/jobs`
- `GET /api/runtime/jobs/:jobId`
- `POST /api/runtime/jobs/:jobId/cancel`

## Security

- Binds to `127.0.0.1` by default.
- Allows only the `liveportrait` provider in Sprint 21.
- Rejects `rawCommand`, `shellCommand`, and `executeCommand` fields.
- Treats `commandPreview` as metadata only.
- Restricts CORS to Vite dev origins.
- Provides no arbitrary file-read API.
- Output paths must be generated by the Runtime Host in a future sprint.

## Token

Development mode allows empty token.

For production-like local use, set:

```bash
set RUNTIME_HOST_TOKEN=your-token
```

Requests must then include:

```text
x-runtime-token: your-token
```

## Current Mock Mode

Sprint 21 does not execute LivePortrait.

Jobs move through:

```text
queued -> running -> completed
```

The completed output is mock metadata only.

## Dry Run Mode

Sprint 22 adds `mode: "dryRun"` for LivePortrait.

Dry run does not execute Python, FFmpeg or LivePortrait. It only generates:

- `commandPlan`
- `outputPlan`
- `dryRun: true`

Example request:

```json
{
  "providerId": "liveportrait",
  "providerKind": "portrait-motion",
  "mode": "dryRun",
  "runtimeConfig": {
    "mode": "localCli",
    "runtimePath": "D:/ai-runtimes/LivePortrait",
    "pythonCommand": "python",
    "entryFile": "inference.py",
    "outputDir": "D:/ai-wallpaper-runtime-outputs/liveportrait"
  },
  "input": {
    "sourceAssetId": "current-wallpaper",
    "sourceImagePath": "D:/images/source.png",
    "preset": "blink",
    "strength": 0.5,
    "duration": 5,
    "loop": true
  }
}
```

The Runtime Host generates output filenames itself. The browser must not provide arbitrary executable commands or output file paths.

## Future LivePortrait CLI

A future sprint can add an explicit opt-in CLI runner that maps validated job input to a known LivePortrait command. The frontend should still never send arbitrary executable command strings.
